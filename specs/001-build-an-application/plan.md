## Summary
Build an intelligent fantasy football management assistant that integrates with Sleeper API to provide strategic recommendations for lineup management, trades, keeper selections, and dynasty transition planning. The system will use conversational AI through Claude Code integration, leveraging Elixir/Phoenix with Ash framework for declarative development and Ash.ai for AI capabilities. Includes comprehensive NFL data gathering, caching, and both short-term and long-term strategy optimization for keeper/dynasty leagues.

## Technical Context
**Language/Version**: Elixir ~> 1.15 with Phoenix v1.8.1  
**Primary Dependencies**: Ash Framework (https://hexdocs.pm/ash/readme.html), Ash.ai (https://github.com/ash-project/ash_ai), Ecto for PostgreSQL  
**Storage**: PostgreSQL for data persistence, caching layer for API responses  
**Testing**: ExUnit with Ash testing utilities  
**Target Platform**: Linux server (web application)
**Project Type**: web (backend API + potential frontend interface)  
**Performance Goals**: <500ms API response time, efficient caching for external API calls  
**Constraints**: Must integrate with existing Claude Code installation, handle API rate limits (Sleeper API, api.sports.io)  
**Scale/Scope**: Single user application, support for multiple leagues per user, historical data retention
